# 07. 처음 시작자용 전체 체크리스트

초보자가 한 번에 실행할 수 있게 **단일 흐름**으로 정리합니다. 이 파일의 내용은 `docs/00-처음-시작자-일괄-설정-가이드.md`를 그대로 따르는 축약 버전입니다.

## 실행 순서 (한번에)

1. 네이버클라우드에서 Ubuntu 인스턴스 생성 (`SSH 키/퍼블릭IP 확인`)
2. 서버 접속 후 `apt update` 및 기본 패키지 설치
3. Hermes 설치
4. 리포지토리 clone
5. `bootstrap-datest.sh` 실행 (봇 토큰/허용 사용자/기본 채널 지정)
6. cron 4개 등록 및 수동 실행 확인
7. `datest send --list telegram`, `datest cron list`로 상태 확인
8. `datest gateway start`
9. Telegram 테스트 메시지 수신 확인

> 실제 토큰/채널 ID는 넣지 않았고, 실행 시 placeholder로 대체합니다.

---

## 원클릭(최대한도) 실행 예시

```bash
cd /tmp/Simple-hermes-setting-with-Naver-cloud-Server

chmod +x scripts/bootstrap-datest.sh

TELEGRAM_BOT_TOKEN=<TELEGRAM_BOT_TOKEN> \
TELEGRAM_ALLOWED_USERS=<USER_ID_OR_IDS_COMMA_SEPARATED> \
TELEGRAM_HOME_CHANNEL=<CHAT_OR_CHANNEL_ID> \
PATH=$HOME/.local/bin:$PATH \
./scripts/bootstrap-datest.sh

export PATH=$HOME/.local/bin:$PATH

datest cron run datest-daily-goal
datest cron run datest-weekly-goal
datest cron run datest-monthly-goal
datest cron run datest-2h-schedule
PATH=$HOME/.local/bin:$PATH datest gateway start
```

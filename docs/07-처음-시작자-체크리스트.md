# 07. 처음 시작하는 사람용 한 번에 보는 실행 순서

1. 네이버 클라우드에서 Ubuntu 인스턴스 생성
2. SSH 접속
3. Hermes 설치
4. `datest` 프로필 생성 (`hermes profile create datest --clone`)
5. `~/.hermes/profiles/datest/.env` 작성 (봇 토큰/허용 사용자)
6. `scripts/datest_*.py`와 `scripts/datest_reminder_engine.py`를 datest/scripts로 복사
7. 데이터 파일 초기화: `scripts/datest_data_template.json`
8. 크론 4개 등록 (일간/주간/월간/2시간)
9. `hermes gateway start` 또는 `datest gateway start`
10. `datest send --list telegram`로 대상 확인
11. 네 가지 cron을 수동 실행해 동작 체크
12. GitHub에 저장소 업로드(아래 참고)

## 운영 체크

- 일간/주간/월간 목표: 매일/매주/매월 리마인드
- 2시간 알림: 일정이 없으면 무음(no-op)
- 기존 `default`는 그대로 유지해서 기존 봇은 절대 덮어쓰지 않음
- 민감정보는 `.env`에서만 관리 후 즉시 `chmod 600` 권장

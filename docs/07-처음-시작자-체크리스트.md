# 07. 처음 시작자용 전체 체크리스트

`docs/00-처음-시작자-일괄-설정-가이드.md`가 이미 AI 실행형 원클릭 절차를 담고 있습니다. 빠른 체크만 보고 싶다면 아래를 확인하세요.

- 네이버클라우드에서 Ubuntu VM 생성(SSH 접속 가능)
- `git`, `curl`, `python3` 설치
- Hermes 설치 후 `hermes --version` 확인
- 레포 clone 후 `bootstrap-datest.sh` 실행
  - `TELEGRAM_BOT_TOKEN`
  - `TELEGRAM_ALLOWED_USERS`
  - `TELEGRAM_HOME_CHANNEL`
- `datest` profile/cron 등록 확인 (`datest cron list`)
- Telegram 발송/수신 확인 (`datest send --list telegram`)
- 문제 발생 시 `06-문제-해결-체크리스트.md`의 A~F 항목으로 복구

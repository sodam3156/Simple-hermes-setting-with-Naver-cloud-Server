# 07. 처음 시작자용 전체 체크리스트

`docs/00-처음-시작자-일괄-설정-가이드.md`가 AI 실행형 원클릭 절차의 원문입니다.

- VM 생성 후 SSH 접속
- `git`, `curl`, `python3` 준비
- 저장소 클론
- 다음 필수 환경변수 설정 후 실행
  - `TELEGRAM_BOT_TOKEN`
  - `TELEGRAM_ALLOWED_USERS`
  - `TELEGRAM_HOME_CHANNEL`
- `bash scripts/bootstrap-datest.sh` 실행
- 완료 체크: `datest send --list telegram`, `datest cron list`, `datest cron run ...`
- 실패 시 `06-문제-해결-체크리스트.md` 또는 00 문서의 A~D 블록 적용

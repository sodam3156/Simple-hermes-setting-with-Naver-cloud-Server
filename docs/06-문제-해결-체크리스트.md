# 06. Trouble Shooting & 점검 체크리스트

## A. `datest: command not found`

원인: `PATH` 미설정

```bash
PATH=$HOME/.local/bin:$PATH
which datest
```

- 정상: `~/.local/bin/datest`
- 비정상: not found

## B. cron은 생겼는데 알림이 안 옴

1. 크론 상태
   ```bash
   PATH=$HOME/.local/bin:$PATH datest cron list
   ```
2. 최근 실행 이력
   ```bash
   PATH=$HOME/.local/bin:$PATH datest cron runs datest-2h-schedule --limit 5
   ```
3. gateway 상태
   ```bash
   datest gateway status
   hermes gateway list
   ```
4. Telegram 대상
   ```bash
   PATH=$HOME/.local/bin:$PATH datest send --list telegram
   ```

## C. 경보 텍스트가 너무 자주 비어있음/메시지 없음

- 2시간 스크립트(no-op)는 일정이 없으면 빈 출력 처리(`if out: print(out)`)가 정상.
- 일정이 있어도 `schedules`의 `status`가 `done`이면 제외됨.

## D. `datest config get ...`가 찾지 못함

`default`/`profile` 설정 조회 동작은 환경/버전별 차이가 있어 CLI가 값을 읽지 못할 때가 있습니다.
권장 우회:

- 환경은 `.env`(프로필 경로)에 직접 기록한다.
- `send --list`/실제 발송, `hermes gateway list`, `gateway status` 중심으로 운영 진단한다.
- 값 검증은 민감정보를 가리지 말고 실제 메시지/로그로 확인한다.

## E. gateway restart 실패

- 먼저 상태를 정리:
  ```bash
  hermes gateway list
  datest gateway status
  ps -ef | grep -i hermes | grep datest
  ```
- 서비스 재시작:
  ```bash
  datest gateway stop
  datest gateway start
  ```
- 그래도 안 되면 systemd 로그 확인:
  ```bash
  journalctl --user -u hermes-gateway-datest.service -n 80 --no-pager
  ```

## F. 방화벽/포트 확인(원격 수신형 운영)

- 기본 폴링 모드면 서버 아웃바운드 연결이 필요.
- 웹훅 모드는 인바운드 443/포트포워딩/도메인 설정 추가 검토.

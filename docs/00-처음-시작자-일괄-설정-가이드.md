# 00. 처음 보는 사람·AI에게 넘겨 바로 끝내는 Datest 셋업 가이드

이 문서 **한 장만** 있으면 AI가 네이버클라우드 서버에서 Hermes/datest를 끝까지 구성할 수 있도록 작성했습니다.

> **보안 규칙:** 실제 토큰/사용자ID/채널ID는 절대 넣지 마세요. 실행 시 아래 placeholder를 값으로 교체하세요.

---

## 0) 이 문서를 AI에 그대로 주고 실행시키는 방식

AI에게 할 일은 아래 순서만 지키면 됩니다.

1. 네이버클라우드에서 VM 생성 → SSH 접속
2. 서버 내부에서 의존성 설치
3. Hermes 설치 + 저장소 클론
4. 아래 **원클릭 명령 블록** 실행
5. 완료 검증 4개를 확인

---

## 1) Naver Cloud에서 서버 준비 (UI 단계)

1. Ubuntu 22.04/24.04 기반 VM 생성
2. SSH Key 등록 및 퍼블릭 IP 확보
3. 방화벽: SSH(22) 허용
4. 보안그룹에서 서버 IP만 허용(가능하면)

---

## 2) 서버 접속 후 최소 준비

```bash
ssh -i ~/.ssh/<YOUR_KEY>.pem ubuntu@<SERVER_PUBLIC_IP>

sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl ca-certificates jq python3 python3-venv python3-pip
```

---

## 3) Hermes 설치 + 레포 클론

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc

# datest 경로 보정
export PATH="$HOME/.local/bin:$PATH"
hermes --version

cd /tmp
git clone https://github.com/sodam3156/Simple-hermes-setting-with-Naver-cloud-Server.git
cd /tmp/Simple-hermes-setting-with-Naver-cloud-Server
```

---

## 4) AI가 바로 실행할 **원클릭 블록**

아래 블록은 AI에게 그대로 실행 지시하면 됩니다.

```bash
cd /tmp/Simple-hermes-setting-with-Naver-cloud-Server

chmod +x scripts/bootstrap-datest.sh

export TELEGRAM_BOT_TOKEN=<TELEGRAM_BOT_TOKEN>
export TELEGRAM_ALLOWED_USERS=<USER_ID_OR_IDS_COMMA_SEPARATED>
export TELEGRAM_HOME_CHANNEL=<CHAT_OR_CHANNEL_ID>

# 한 번에 끝내기 기본값
export CREATE_PROFILE=1
export CREATE_CRON=1
export START_GATEWAY=0          # 처음엔 false, 안정되면 1로 변경
export AUTO_VERIFY=1

# PATH 반드시 보장
export PATH="$HOME/.local/bin:$PATH"

bash scripts/bootstrap-datest.sh
```

### 스크립트가 자동 처리하는 것
- `datest` 미설치 시 Hermes 설치/환경 확인
- `datest` profile `datest` 생성(기존 있음 시 유지)
- `~/.hermes/profiles/datest/.env` 생성(실 값은 여기에만 반영)
- `SOUL.md` 생성
- `datest_goal_*.py`, `datest_reminder_engine.py`, `datest_goals_and_schedule.json` 배치
- cron 4개 등록(동일 이름 기존 등록 삭제 후 재등록)
- 기본 검증 명령 실행

## 5) 끝 체크 (반드시 통과)

```bash
export PATH="$HOME/.local/bin:$PATH"

hermes profile list
hermes profile show datest
hermes gateway list

datest send --list telegram
datest cron list

datest cron runs datest-2h-schedule --limit 3

datest cron run datest-daily-goal
datest cron run datest-weekly-goal
datest cron run datest-monthly-goal
datest cron run datest-2h-schedule
```

> 위 항목이 모두 통과하면 “설치·설정 완료”입니다.

## 6) AI가 실패했을 때 바로 쓰는 복구 블록

### A) `datest: command not found`

```bash
export PATH="$HOME/.local/bin:$PATH"
which datest
hermes --version
```

- `which datest`가 비어 있으면 터미널 재시작 + `export PATH=...` 재적용
- 그래도 안 보이면 bash 재실행 후 bootstrap 재실행

### B) `cron`은 있는데 알림이 안 옴
```bash
export PATH="$HOME/.local/bin:$PATH"
datest send --list telegram
datest cron list
datest cron runs datest-2h-schedule --limit 5
datest gateway status
```

### C) gateway가 안 뜸
```bash
datest gateway stop || true
datest gateway start
hermes gateway list
ps -ef | grep -i hermes | grep datest || true
```

### D) 설정값이 반영됐는지 확인
`/root/.hermes/profiles/datest/.env`가 실제 값으로 생성됐는지 확인

```bash
ls -l "$HOME/.hermes/profiles/datest/.env"
cat "$HOME/.hermes/profiles/datest/.env"
```

> 감추기: 값이 실제 값으로 채워졌는지 확인할 수 있으나, **채팅에 붙여넣어 공유하지 말 것**.

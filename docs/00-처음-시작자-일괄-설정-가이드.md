# 00. 처음 보는 사람용 한 번에 끝내는 셋업 가이드

이 문서는 **네이버클라우드 서버 생성부터 Telegram 연동, datest 프로필 자동 설정까지**를 한 번에 진행하는 흐름입니다.

> 이 파일 자체에 토큰/ID 같은 실제 값은 넣지 않습니다.

---

## 0) 전제

- 운영 대상은 Ubuntu 계열 서버 (예: Ubuntu 22.04/24.04)
- 접속 계정: SSH 가능 계정(예: `ubuntu`)
- `default` 프로필은 유지하고 `datest`는 별도 프로필로 운영

---

## 1) 네이버클라우드에서 서버 생성 (UI 작업)

1. [Naver Cloud](https://console.naver.com/) 접속
2. `Server > Server`(또는 Virtual Server)에서 인스턴스 생성
3. 아래 값으로 생성(권장)
   - Ubuntu 22.04 LTS 또는 24.04
   - SSH 공개키 등록
   - 공인 IP 자동 할당
   - 보안그룹: SSH(22) 허용
4. 생성 후 퍼블릭 IP 확인

---

## 2) 서버 접속 및 초기 준비

```bash
ssh -i ~/.ssh/<YOUR_KEY>.pem ubuntu@<SERVER_PUBLIC_IP>

# 서버 내부 기본 패키지
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl ca-certificates jq python3 python3-venv python3-pip
```

---

## 3) Hermes 설치

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc
hermes --version
```

> `datest`가 보이도록 하려면 항상 `PATH=$HOME/.local/bin:$PATH`를 사용하세요.

---

## 4) 리포지토리 내려받고 셋업 스크립트 실행

```bash
cd /tmp
git clone https://github.com/sodam3156/Simple-hermes-setting-with-Naver-cloud-Server.git
git -C /tmp/Simple-hermes-setting-with-Naver-cloud-Server pull
cd /tmp/Simple-hermes-setting-with-Naver-cloud-Server

# 템플릿 값은 직접 입력(복붙 없이 placeholder 교체)
chmod +x scripts/bootstrap-datest.sh
TELEGRAM_BOT_TOKEN=<TELEGRAM_BOT_TOKEN> \
TELEGRAM_ALLOWED_USERS=<USER_ID_OR_IDS_COMMA_SEPARATED> \
TELEGRAM_HOME_CHANNEL=<CHAT_OR_CHANNEL_ID> \
PATH=$HOME/.local/bin:$PATH \
./scripts/bootstrap-datest.sh
```

스크립트가 수행하는 일
- `datest` 프로필이 없으면 `hermes profile create datest --clone`
- `~/.hermes/profiles/datest/.env` 생성 (비밀값은 여기에만 저장)
- `SOUL.md` 기본 규칙 생성
- datest 스크립트 복사
- `datest_goals_and_schedule.json` 초기화
- cron 4개 등록(`daily/weekly/monthly/2h`)

---

## 5) 실행 검증 (초보자가 반드시 확인)

```bash
export PATH=$HOME/.local/bin:$PATH

hermes profile list
hermes gateway list

datest send --list telegram

# cron이 실제로 등록됐는지 확인
datest cron list

# 각 작업 한 번씩 실행해보기
# (성공 메시지가 나오면 정상) 
datest cron run datest-daily-goal
datest cron run datest-weekly-goal
datest cron run datest-monthly-goal
datest cron run datest-2h-schedule

# 실행 이력 확인
datest cron runs datest-2h-schedule --limit 3
```

---

## 6) Gateway 실행(실시간 수신 사용)

```bash
# 데몬 실행(필요 시 1회)
PATH=$HOME/.local/bin:$PATH datest gateway start
```

실행이 안 되면 우선 수동 실행 + 로그로 확인한 뒤 `06-문제-해결-체크리스트.md`를 참고하세요.

---

## 7) Telegram 수신 테스트 메시지

```bash
# 본인 채널/개인챗 ID로 실제 수신 확인
PATH=$HOME/.local/bin:$PATH datest send --to telegram:<CHAT_ID_OR_USER_ID> "datest 연결 테스트 입니다"
```

수신이 되면 완전 세팅 완료입니다.

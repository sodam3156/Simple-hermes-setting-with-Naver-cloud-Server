# 01. 네이버 클라우드 서버 생성부터 접속까지

## 1. 네이버 클라우드 콘솔에서 인스턴스 생성

1. [Naver Cloud](https://console.ncloud.com/) 접속 후 로그인
2. `Server > Server`(또는 Server > Virtual Server) 진입
3. `인스턴스 생성` 클릭
4. 아래 값으로 생성(권장):
   - 지역: `KR`(서울 등 본인 환경에 맞는 리전)
   - 이미지: `Ubuntu 22.04 LTS` 또는 `Ubuntu 24.04`
   - 스펙: 시작은 `vCPU 2 / RAM 4GB` 이상 권장
   - 스토리지: 최소 50GB SSD
   - 공개키 로그인: 본인 공개키 등록(기존 키 사용 가능)
   - 외부 IP: 자동할당(필수)
   - 보안그룹: SSH 포트 22 허용(관리용)

> 초보자용 팁
> - 처음에는 HTTP/HTTPS 열지 않아도 됩니다. 텔레그램/Webhook만 쓰고 메시지 전송이 기본 CLI 기반이면 22번만 있으면 충분합니다.
> - 운영 단계에서만 추가 포트(80/443)를 열어 웹서비스가 필요할 때만 허용하세요.

## 2. SSH 포트 점검

서버 생성 후 대시보드에서 아래를 확인하세요.
- 퍼블릭 IP 확인
- SSH 접속 상태(인스턴스가 running)

## 3. SSH 접속

로컬 터미널에서 접속:

```bash
ssh -i ~/.ssh/<YOUR_KEY>.pem ubuntu@<SERVER_PUBLIC_IP>
```

`~/.ssh/<YOUR_KEY>.pem`는 본인 키 경로로 바꿉니다.

> Xshell/WSL 환경이라면 PuTTY형 키 변환 없이 OpenSSH 형식을 권장하세요.

## 4. 서버 기본 패키지 설치 (최초 1회)

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl ca-certificates jq python3 python3-venv python3-pip
```
